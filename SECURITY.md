# 安全反馈 / Security reporting

如果问题涉及密钥泄露、任意文件访问、命令执行或其他安全风险，请使用 [GitHub 私密漏洞报告](https://github.com/Pumnn1ayLee/PomiPlayer/security/advisories/new)。不要在公开 Issue 中发布利用代码、API 密钥、私人视频或个人路径。

报告请包含受影响的版本、复现条件、预期影响，以及删除敏感信息后的最小复现。当前优先处理最新预览版的问题；不会承诺未经验证的修复时限。

普通播放或界面问题请使用 [Bug 模板](https://github.com/Pumnn1ayLee/PomiPlayer/issues/new?template=bug_report.yml)。提交日志或截图前，请先遮盖账号、密钥与私人内容。

For credential leaks, arbitrary file access, command execution or other security concerns, use [GitHub private vulnerability reporting](https://github.com/Pumnn1ayLee/PomiPlayer/security/advisories/new). Do not publish exploit details, API keys, private videos or personal paths in public issues.

Include the affected version, prerequisites, expected impact and a minimal reproduction with sensitive data removed. Reports concerning the latest preview receive priority; no unverified response or fix deadline is promised.
