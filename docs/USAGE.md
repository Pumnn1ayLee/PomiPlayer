# 使用指南

下载 [0.1.0 Preview 安装包](https://github.com/Pumnn1ayLee/PomiPlayer/releases/tag/v0.1.0-preview)。这个版本仍在完善中，已知问题和安装说明会写在发布页。

## 安装与播放

将播放器安装到有写入权限的目录。设置、播放记录、缓存和模型位于安装目录中，不建议选择受系统保护的目录。普通播放不需要模型、服务账号或管理员权限。

点击打开按钮、使用 `Ctrl+O`，或把本地视频拖入窗口。播放结束后，再按播放键或空格键可从头重新播放。右键菜单提供倍速、逐帧、循环、画面比例、音轨及字幕调整。

## 视频助手

点击“视频助手”或按 `Ctrl+L` 打开侧栏。顶部滑杆图标打开助手性能设置；返回箭头回到助手首页并保留会话，垃圾桶按钮用于清空会话。

| 需求 | 条件 |
| --- | --- |
| 跳到指定时间、暂停、继续播放 | 无需模型。 |
| 按台词关键词查找 | 先加载字幕；可以使用同名字幕、字幕菜单或助手生成的字幕。 |
| 理解对白、讨论内容 | 配置内容模型服务或本地模型，助手按需检索相关字幕。 |
| 询问当前画面、视频概览 | 使用支持图片的模型；云端画面发送需单独授权。 |
| 生成 SRT 或 VTT | 准备兼容的 Whisper GGML 语音模型。 |

可以继续追问，也可以直接聊其他话题。界面会展示处理阶段、实际耗时和简短依据摘要，这不等同于模型的内部推理全文。视频时间需核对对应依据；概览中的时间按钮由你点击跳转。

## 连接云服务

在“设置 → 内容模型”填写服务地址、模型名称与 API 密钥，保存后使用。服务需要兼容 Chat Completions；图片问答还需要模型及接口支持图片输入。

云端服务由用户自行选择和付费，PomiPlayer 不提供共享账号、额度或内置密钥。连接服务不代表已确认其连通性，也不等于已授权发送采样画面。密钥与服务设置由 Windows DPAPI 保护，复制到其他 Windows 账户后可能无法解密。

普通问答发送问题及相关上下文；指向当前视频的问题可能附带相关字幕。只有另行授权后才发送采样画面。请先了解所选服务的数据处理条款。

## 本地模型与性能

标准安装包不附带语言模型权重或 GPU 推理组件。使用本地推理前需准备相应运行库与兼容模型；视觉模型可能还需要配套视觉编码文件。组件是否提供以及适用硬件，以发布说明为准。

助手性能中可调整上下文、GPU 分担、批处理、图像预算、回答上限和空闲释放。优先尝试节省资源预设，再逐项调整。缩短上下文不会同步缩小模型权重；将计算转到 CPU 也不代表系统内存占用会一起下降。

播放器不会仅因打开助手而自动加载语言模型，也不会在本地模型停用后自动改用云端。不同模型的效果、语言能力与资源占用可能有明显差异。

## 生成字幕

输入“生成字幕”，选择 SRT 或 VTT。可以保存到视频所在目录，也可以自定义路径。默认命名为 `视频名.pomiplayer.srt` 或 `视频名.pomiplayer.vtt`。

开始前选择兼容语音模型。完成后字幕自动加载，视频助手可继续使用。已有文件不会被直接覆盖；发生错误或取消时保留原字幕。首次使用建议先用短视频验证转写速度和结果。

## 常用快捷键

| 按键 | 操作 |
| --- | --- |
| `Space` | 播放、暂停或片尾重播 |
| `Left` / `Right` | 后退或前进 5 秒 |
| `Up` / `Down` | 调整音量 |
| `M` | 静音或取消静音 |
| `F11` | 切换全屏 |
| `Ctrl+O` | 打开视频 |
| `Ctrl+L` | 打开视频助手 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+S` | 保存当前画面 |

以上为默认配置，可在设置中修改。输入框获得焦点时，`Enter` 发送，`Shift+Enter` 换行；中文输入法确认候选时不会直接发送问题。

## 语言、主题与卸载

首页右上角与设置提供同步的语言选择器，切换无需重启。新回答默认跟随界面语言，明确指定回答语言时优先遵从；历史对话与字幕原文不重新翻译。

太阳或月亮图标切换主题，齿轮图标打开设置。卸载仅移除安装清单中的程序文件，保留个人设置、缓存与自行添加的模型；彻底删除这些数据前请自行备份。
