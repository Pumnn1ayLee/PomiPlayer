# PomiPlayer 隐私政策

更新日期：2026 年 11 月 20 日

本政策适用于 PummyLee 发布的 PomiPlayer，说明播放器及可选视频助手如何处理信息。

## 1. 本地播放与保存的信息

基础播放无需注册 PomiPlayer 账号，也不需要连接 AI 服务。打开本地视频时，播放器在设备上读取所选视频、音轨和字幕，用于播放、检索及用户发起的分析任务。

为保留使用偏好和提高处理效率，应用会在本地保存设置、最近打开的文件名称与路径、模型配置，以及使用相关功能时生成的视频分析索引、时间线摘要、运行日志和性能记录。分析索引可能包含画面描述及其他由视频内容生成的文字，不应视为不含私人内容的普通缓存。

当前版本不将聊天记录单独保存为本地历史文件，退出应用后不恢复会话。视频分析索引、任务产物、运行库日志以及你主动保存的字幕或截图可能继续保留，不随会话清空而全部删除。

Microsoft Store 版将设置与缓存保存在应用的私有数据位置；独立 EXE 版保存在播放器目录。字幕和截图保存到相应功能指定的位置，生成字幕默认保存至视频所在目录。

## 2. 本地 AI 与字幕转写

选择本地模型时，相关问题、字幕和采样画面交给本机模型处理；当前内置的字幕转写流程在本机处理提取的音轨。使用这些本地流程不需要把内容发送给开发者。

模型与可选运行库由用户自行准备。自行安装的第三方工具或运行库可能有其独立的数据处理行为，应同时查阅其说明。若随后使用云端助手询问转写内容，相关字幕仍可能按下一节所述发送给所选服务。

## 3. 可选模型服务与对外传输

视频助手支持用户自行配置模型服务。普通云端聊天会发送本次问题及为理解对话所需的近期上下文；针对当前视频的问题，可能附带相关字幕、时间信息、片长及此前生成的内容描述。只有单独开启“允许发送采样画面”后，应用才会按任务需要向所选服务发送采样图片。

当前内置流程不会向模型服务上传完整视频文件或原始音轨，但字幕、图片和分析文字本身仍可能包含私人或敏感信息。

请求直接发送到你配置的服务地址。服务会收到必要的网络信息，例如 IP 地址、请求时间，以及用于认证的 API 密钥。服务地址若指向远程服务器，即使它使用的是开源或自行部署的模型，也属于对外传输。使用本机回环地址的服务则在本机通信。

服务方如何保留请求、是否使用内容训练模型、处理地点及删除方式，由其政策和你与该服务的约定决定。PomiPlayer 不承诺第三方服务“不留存”或“不用于训练”。所选服务可能在你所在地区之外处理数据，请在启用前了解其条款。普通播放不要求配置此类服务。

## 4. 密钥保护与诊断

应用使用 Windows 数据保护机制（DPAPI）保护保存在本地的模型服务设置及 API 密钥。远程模型请求使用 HTTPS，本机回环服务可使用 HTTP。这些措施不能防止已控制当前 Windows 账户或设备的软件读取使用中的信息。

当前版本未集成广告追踪、使用行为分析或向开发者自动上传日志的功能。运行日志、转写日志及本地运行库日志可能包含文件路径、错误详情、处理内容或模型输出。向外提供日志前，请先检查并删除私人内容和凭据。

通过 Microsoft Store 安装、更新或使用应用时，微软可能依据其隐私声明处理商店使用与诊断信息；开发者可能获得微软后台提供的统计或诊断资料。这与播放器向模型服务发送内容是不同的处理流程。详见 [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)。

## 5. 你的选择与删除方式

- 在“设置 → 内容模型”断开外部服务，可停止后续使用该连接并清除应用保存的该连接配置；关闭“允许发送采样画面”可停止后续画面发送。正在执行的任务可通过停止按钮取消。取消任务或断开连接不能撤回已经发送的数据。
- 在“设置 → 记录与数据”清除最近打开记录；助手的清空会话按钮用于移除当前可见会话，不会同时删除视频索引、日志或已导出的文件。
- 退出应用后，可以手动删除不需要的本地索引、缓存、日志和配置。删除前请备份需要保留的设置、模型、截图及字幕。
- Store 版可使用 Windows 的应用重置或卸载功能清除由系统管理的应用数据；自行保存在外部目录的字幕、截图和模型需要另行删除。独立 EXE 版卸载会保留个人设置、缓存和模型，需要用户自行删除。
- 已发送至第三方模型服务的内容，应按该服务提供的方式申请查询或删除，开发者无法代替服务方直接删除其副本。

## 6. 反馈与第三方平台

向开发者提交问题时，开发者会收到你主动提供的描述和附件，并将其用于沟通与排查。GitHub 公开 Issue 中的内容对其他人可见，请勿提交 API 密钥、私人视频、未脱敏的字幕或日志。

反馈资料在沟通和排查所需期间保留。你可以通过下述联系渠道提出删除请求；已公开内容或平台自身留存，还需按相关平台提供的方式处理。

GitHub、Microsoft Store 及用户自行选择的模型服务分别适用其自身的隐私政策。PomiPlayer 当前未提供用于接收用户视频或对话的开发者中转服务，也未提供在应用内把这些内容出售或用于广告投放的功能。

## 7. 政策更新与联系

应用功能或数据处理方式发生变化时，将相应更新本政策并标明日期。若新的处理活动需要额外授权，会在相关功能启用前提供相应说明和选择。
